## 🔌 2. Ethernet Cable Preparation

Prepared two different types of Cat6 Ethernet cables:

- Flat Cat6 Ethernet cable
- Round Cat6 Ethernet cable

### Procedure

1. Measured and cut the Ethernet cables.
2. Carefully removed the outer cable jackets.
3. Identified the eight internal conductors.
4. Arranged the conductors according to the T568B wiring standard.
5. Straightened and trimmed the conductors.
6. Inserted the conductors into compatible RJ45 connectors.
7. Crimped the connectors using an RJ45 crimping tool.
8. Repeated the process on the opposite ends.

Both cables were terminated using T568B on each end to create straight-through Ethernet cables.

### T568B Wiring Standard

| Pin | Wire Color |
|-----|------------|
| 1 | White/Orange |
| 2 | Orange |
| 3 | White/Green |
| 4 | Blue |
| 5 | White/Blue |
| 6 | Green |
| 7 | White/Brown |
| 8 | Brown |

## 🧪 3. Cable Testing & Validation

After completing both cable terminations, performed functional connectivity testing and dedicated cable tester validation.

### Test 1: Functional Ethernet Connectivity

Connected each terminated cable between a Windows laptop and the home network.

### Validation Steps

1. Connected the Ethernet cable to the laptop.
2. Connected the opposite end to the network.
3. Disabled Wi-Fi to isolate the wired connection.
4. Verified Ethernet connectivity in Windows.
5. Confirmed successful internet access.
6. Repeated the test using the second cable.

### Results

| Cable | Ethernet Connection | Internet Access |
|-------|---------------------|-----------------|
| Flat Cat6 | PASS | PASS |
| Round Cat6 | PASS | PASS |

Both cables successfully established functional Ethernet connections.

### Test 2: Dedicated Ethernet Cable Tester

After obtaining the required batteries, both terminated Cat6 cables
were tested using a dedicated Ethernet cable tester.

#### Testing Procedure

1. Connected both ends of each cable to the tester.
2. Powered on the tester.
3. Observed the LED sequence cycling through pins 1–8.
4. Verified the corresponding pin indicators illuminated in sequence.
5. Repeated the procedure for both cables.

#### Test Results

| Cable Type | Wiring Test | Result |
|------------|-------------|--------|
| Flat Cat6 | Pins 1–8 verified | PASS |
| Round Cat6 | Pins 1–8 verified | PASS |

**Result:** Both cables passed basic wire-map testing,
with no wiring faults observed.

> Note: The cable tester uses sequential LED indicators.
> Results were verified through direct observation rather
> than photographic evidence.

A basic cable tester verifies wiring continuity and certain
termination faults.

## 🔍 4. Observations & Challenges

### Flat Cat6 Cable

The flat Cat6 cable contained thin conductors that were more difficult to handle during termination.

The conductor size and cable construction required additional care when preparing and inserting the wires into the RJ45 connector.

**Result:** Successfully terminated the cable and verified connectivity.

### Round Cat6 Cable

The round Cat6 cable contained four twisted pairs and an internal separator.

During preparation, the separator was removed, and the conductors were arranged using T568B.

A transparent wire guide was used to assist with conductor alignment before inserting the wires into the RJ45 connector.

**Result:** Successfully terminated the cable and verified connectivity.

### Cable Tester

The dedicated cable tester could not initially be used because the required batteries were unavailable.

Functional Ethernet testing was performed first.

Once the batteries were obtained, both cables were tested successfully.
