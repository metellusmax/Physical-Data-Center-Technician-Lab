# 🖥️ Physical Data Center Technician Lab


## 📌 Project Overview

This project is a hands-on physical infrastructure lab designed to develop practical skills relevant to **Data Center Technician (DCT)** roles.

Using a **Dell OptiPlex 7010 SFF**, I am building experience in hardware servicing, storage installation, bare-metal Linux deployment, physical networking, structured cabling, and infrastructure troubleshooting.

The project emphasizes repeatable technical procedures, hardware validation, documentation, and operational best practices.

**Project Status:** 🚧 In Progress


## 🎯 Project Objectives

- Perform hardware intake, inspection, and asset documentation
- Identify and service internal hardware components
- Practice RAM removal, installation, and validation
- Inspect existing storage and install an additional SATA SSD
- Configure BIOS/UEFI settings and run hardware diagnostics
- Deploy Ubuntu Server directly onto physical hardware
- Perform Linux hardware inventory and system administration
- Configure physical Ethernet networking and remote access
- Practice Ethernet cable termination, testing, and labeling
- Explore managed switch configuration and VLAN segmentation
- Develop infrastructure deployment and maintenance procedures
